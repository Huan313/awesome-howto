# 生活资源

- [Anduin2017/HowToCook](https://github.com/Anduin2017/HowToCook)。用分步配方整理常见家常菜，面向家长和新手。
- [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)。汇集生活、管理和个人成长经验，面向一般读者。
- [geekan/HowToLiveLonger](https://github.com/geekan/HowToLiveLonger)。将健康和寿命相关主题整理成资料索引，面向进阶读者。
- [QERSSD/HowToAvoidScams](https://github.com/QERSSD/HowToAvoidScams)。记录常见骗局与警示线索，面向一般读者与照护者。
- [kkk-bot/HowToGetAlong](https://github.com/kkk-bot/HowToGetAlong)。整理常见人际交往场景，面向一般读者。
- 手机和电脑的备份范围差异，参阅 [Apple 备份方法](https://support.apple.com/en-us/108771) 和 [Microsoft Windows 恢复概览](https://support.microsoft.com/en-us/windows/experience/backup-recovery/backup-restore-and-recovery-in-windows)。
