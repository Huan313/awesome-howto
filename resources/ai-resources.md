# AI 技能资源

- [microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners)。用课程与练习介绍生成式 AI，面向初学开发者。
- [openai/openai-cookbook](https://github.com/openai/openai-cookbook)。OpenAI API 实践案例，面向已有编程基础的学习者。
- [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide)。整理提示方法及配套阅读，面向写作者和开发者。
- [huggingface/agents-course](https://github.com/huggingface/agents-course)。以单元和作业组织 Agent 学习，面向 Python 学习者。
- [NirDiamant/GenAI_Agents](https://github.com/NirDiamant/GenAI_Agents)。集中展示生成式 Agent 的实现模式，面向 Python 开发者。
- [K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)。面向科研工具和分析任务的 Skill 目录，面向研究人员。
- [anthropics/skills](https://github.com/anthropics/skills)。Anthropic 发布的 Agent Skills 示例，面向作者和开发者。
- [obra/superpowers](https://github.com/obra/superpowers)。按 Skill 组织软件开发流程，面向 AI 辅助开发者。
- [mattpocock/skills](https://github.com/mattpocock/skills)。提供以开发实践为中心的 Skill 集合，面向工程团队。
- [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)。围绕最近三十天的内容研究提供 Skill，面向研究者和维护者。
- 查阅 [Codex CLI 文档](https://learn.chatgpt.com/docs/codex/cli) 和 [Codex Action](https://github.com/openai/codex-action) 了解运行范围。

完整元数据见 [GitHub 索引](awesome-howto-projects.md)。
