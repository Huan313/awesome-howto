# 怎样比较几门付费课程的内容和总投入？

用相同问题比较三门课程的产出、时间、成本和规则，再决定是否继续试学。

## 适用人群

正在比较成人职业训练、线上课程或短技能项目的学习者。

读者标签　学生、求职者、职场人士、一般读者。

## 前置条件与不适用情况

先写明你需要的可验证能力。学历、认证和职业准入因地区而异，需向签发机构或当地主管机关查询。

## 准备、耗时与费用

找三家机构的公开大纲、价目、课程样例和规则。约 30–60 分钟，比较阶段可免费完成。

## 操作步骤与验收

1. 把「想学好」改成能展示的任务。例如虚构目标「用一份样例数据做三张能口头解释的图」。 **验收**　目标包括一个可产出的作品和验收标准。
2. 用同一张表填三门课的作业、反馈方式、计划工时、学费、工具费和额外考试费。 **验收**　每项有书面出处或标为未知，币种和费用周期清楚。
3. 查看试课与样例作业，核对证书签发者、雇主接受情况及退出规则。将口头宣传另记。 **验收**　能够指出实际产出和两项需确认的条款。
4. 给自己一个复核期限，保留免费学习或短试学方案作为备选。 **验收**　判断有可追溯依据，并写清触发改变决定的条件。

## 常见错误与排查

营销材料提到就业率时，查统计分母、调查时间和就业定义。找不到时把它记为未证实宣传。

## 风险与限制

FTC 来源面向美国职业院校与认证项目，表格方法可用于其他地区。当地认可和合同条件以当地机构的现行书面规定为准。

## 最简行动清单

写产出 → 同表比较 → 查样例与条款 → 留时间决定。
