# 怎样用一个两小时小项目验收新软件技能？

练习日志区分独立完成、参考资料后完成和未完成。 本稿记录了资料核对，操作待实测。

## 适用人群

选择一个能在两小时内交付的小任务，并有可打开的官方教程。以下做法是练习安排。

## 前置条件与不适用情况

两小时时间是编辑建议。提取和间隔复习的研究支持有限任务的实践，不直接证明该项目练习的效果。

## 准备、耗时与费用

使用三行虚构记录练习导入、加总、排序和导出。预先计算 `20+35+45=100`。 预计 约两小时，翌日复测，可选免费工具和虚构数据。

## 操作步骤与验收

1. 写验收表：`应读入 3 行、总额 100、金额降序、可导出再打开`。留一份未碰过的测试数据。 **验收**　每项明确写出输入和独立核验方式。
2. 读一段当前软件教程并运行一遍。合上教程，使用测试数据重新完成任务。 **验收**　导出文件能独立打开，行数、总额、顺序都吻合。
3. 次日换三行数字重做，并给同事或同学演示。在卡住的位置写下下一次练习题。 **验收**　练习日志区分独立完成、参考资料后完成和未完成。

## 常见错误与排查

软件版本菜单不同就按功能词搜索官方文档。无法算清指标时缩小任务，再把检验做成一次可复演的动作。

## 风险与限制

两小时时间是编辑建议。提取和间隔复习的研究支持有限任务的实践，不直接证明该项目练习的效果。 关键条件无法确认时停止并保留原始数据。

## 最简行动清单

设小任务 → 提前写验收 → 闭卷重做 → 次日换数据。
