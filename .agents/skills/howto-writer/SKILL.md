# howto-writer

## 输入与目标

具体任务、来源清单、证据及读者条件。先写最简单的方法。

## 流程与输出

按指南模板写操作和成功检查，再评估国产 AI 或 Skills、Agent、MCP 是否确有帮助。社交输出包含正文、标签、分镜、口播、字幕和自然互动，存本地。

## 失败与安全

确认版本、地区、账户、成本和数据边界。只写已知能力。测试缺失时标明，需要人审则保持待审。

## 示例与验收

Windows 空间样例。核对微软存储入口，先读容量和分类再考虑可删项。实测仅为只读时，结论只覆盖只读检查。
