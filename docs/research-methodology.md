# 热点研究方法

观察包括窗口、平台、公开 URL、查询词、事件和采集时间、方式、指标及样本限制。GitHub push 是项目活动，RSS 是发布事件，明确任务或问题才计入需求。不同平台指标分别记录。

## V2 与基线

基线 `score_group` 保留供对比。V2 `score_group_v2` 使用需求 30%、可比趋势 15%、人群 10%、证据准备 25%、可执行性 15%、空白 5%。未知项在数据中保留 unknown，对加权贡献为零。覆盖率是已知项比例，置信度同时考虑样本和证据。样本按平台与公开 URL 去重。只有同平台、指标、对象和查询的不同时点可算变化。多个平台或日期的收录数量另列。

标题、任务和概括共同参与分类。人群取可查自述、调查或已审研究。解决方案证据取已审原始矩阵。先判风险和重合范围，再决定研究、候选、观察、更新、拦截或暂缓。

## 研究到草稿

月报保存当前和历史的 source_refs、真实 topic_id、需求、趋势、风险和缺口。证据包经过编辑审核，再以真实需求 URL 与当期选题匹配。Codex 只选排已受支持的步骤。无足够证据时只提供后续研究计划。[证据包规范](../data/evidence/README.md)
