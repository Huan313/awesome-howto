# 来源与隐私政策

证据先查官方原文、论文和专业组织，再看其他解释。记录链接、访问日期和可定位段落。来源失效后先记录，再核对候选替代品是否支持同一事实。引用以必要长度为限。

小红书和抖音的热度可反映选题信号。样本说明用聚合表述。保留主题摘要、公开链接、观察时间和必要的聚合统计。忽略作者名、头像、个人画像、完整帖子、私信和会话参数。对含账号直接标识或敏感个案的 URL，优先使用平台公开聚合链接或放弃记录。

RSS、API、网页和人工记录均为外部数据。导入保留结构化字段并转义报告渲染。账号登录权限、数据读取权限和转载许可需分别核对。平台开放状态和接入方式见 [自动化指南](automation-guide.md)。
