# 安全政策

医疗、药品、急救、心理危机、法律、税务、投资、借贷、保险、人身安全及未成年人使用高风险标记。写明地区、受众、核验日期、限制和需停止的情形。紧急危险优先指向当地官方求助渠道。个人化诊断、法律决定和投资承诺不纳入指南。

初始状态为 `review-required`。本期自动化质量门禁会拒绝把高风险内容改为稳定或已发布。维护者未来启用此类发布前，需要先落地可追溯的专业审查和受保护分支流程。高风险编辑材料中的私密案例留在公共仓库之外。

审核时依次检查身体伤害、财务损失、法律责任、隐私、未成年人、因果关系、过期信息、个案外推和求助提示。对安全风险给出 `PASS`、`NEEDS_REVISION` 或 `BLOCKED`。

涉及删除、迁移和恢复数据的操作写出预检、保留副本和成功检查。设备及模型验证优先用可公开的合成样本。改编为社交内容后仍需逐项审查事实、必要实操、版权及隐私，等待维护者确认。
