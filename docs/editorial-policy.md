# 编辑政策

标题描述可以完成和核对的任务。每一步写输入、动作和验收。注明地区、费用、耗时、工具版本、排查方法和停止条件。虚构例子需标明。

在 claim_evidence 逐项记录主张、出处、段落、版本、适用范围和审核状态。区分事实、经验、推断、建议与未知。缺少真实设备或任务演练时把 execution_status 置为 pending。

初步需求进入 idea 或 needs-research。正文从 draft 进入 editorial-review 或 expert-review。实际核验与合格的人审完成后才进 published。失效指南标记 needs-update，退役版本保留历史。
