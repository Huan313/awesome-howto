# 编辑政策

标题描述一个可完成的任务。正文覆盖适用人群、前置与排除条件、材料、耗时费用、逐步验收、故障排查、风险限制、行动清单、来源和复查日期。

每条关键事实需要定位到来源的章节或段落。作者经验、推论和待验证假设应显式标记。示例应标注虚构。工具教程写明系统、产品范围、版本或订阅前提。

状态依次为 `draft`、`stable` 和 `published`，高风险另用 `review-required`，淘汰用 `retired`。草稿在仓库中可见，读者应按状态判断成熟度。

新专题以读者实际要完成的任务为入口，分别记录需求、事实与实操证据。优先写可直接执行的基础做法。AI 增强和自动化按收益、适用条件与失败处理补充。来源核验到的内容、合成样本的结果和真实设备的验证范围按[证据政策](evidence-policy.md)分别标注。
