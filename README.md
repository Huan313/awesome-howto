## 收录与贡献

优先收录能完成一个具体任务、可打开原文、用途和范围明确的资源。每条资源保留一个主入口，其他主题按需引用。欢迎提供原始链接或修正适用范围。[贡献指南](CONTRIBUTING.md)

涉及中国大陆的医疗、法律、财税和公共安全操作，使用当前主管部门依据并经人工复核。地区敏感资源须按标注范围使用，个人决策由适当的专业人员判断。
