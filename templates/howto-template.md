# HowTo 指南模板

复制下面字段到指南顶端，使用三个连字符包围元数据。由作者填写实际来源，元数据的来源须在正文逐条列出。

```yaml
id: howto-unique-slug
title: 具体问题导向的标题
category: learning
subcategory: study-methods
personas: [student]
age_groups: [unknown]
occupations: [not-applicable]
life_stages: [unknown]
scenarios: [skill-learning]
region: unknown
prerequisites: []
difficulty: beginner
estimated_time: 30 分钟
cost: 免费
evidence_level: pending
content_type: howto
risk_level: low
status: draft
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
review_due: YYYY-MM-DD
last_verified_at: pending
version: '0.1'
execution_status: pending
sources: []
claim_evidence: []
```
