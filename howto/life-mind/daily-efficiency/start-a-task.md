# 大任务迟迟没开始，怎样先做出一个小结果？

一句话解法：把任务改写成十分钟内能看见结果的一步，然后安排一次重启入口。

## 适用与准备

适用于日常学习或工作任务。准备一个计时器和一张纸。任选一个自己可以决定何时开始、没有紧急安全风险的任务。

## 基础档

1. 从“整理文件”这样的目标缩小为可观察动作，例如“在临时清单中登记三个文件名”。
2. 设十分钟。第一轮只交付这一步，遇到障碍写下一句具体原因。
3. 到时留下产物和下一步。继续、缩小步骤或稍后回来，按当前状态选择。

## 成功检查

手边有一个可见的小结果，以及写清楚的下一步。若仍无法开始，把动作缩到两分钟，先验证是不是准备条件缺失。

## 证据与核验

这是可逆的日常任务练习。2026-11-25 核对了示例、完成标准和可逆步骤。对情绪或长期习惯的影响未测量。2026-11-26 复核了 UNC 医学院写作讲义的第 62–63 张幻灯片，其中建议先写十分钟，再把大任务缩小到可完成的一段或一句。[UNC 医学院写作讲义](https://www.med.unc.edu/facultyaffairs/wp-content/uploads/sites/427/2024/06/Getting-it-Done.pdf)
