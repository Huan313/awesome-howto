# 按人群、阶段和技能浏览

## 求学与入职

- 在校学生可从[文献检索与整理](../catalog/learning-research.md#查找和整理资料)开始。
- 初入职场或准备实习，可查[面试与求职材料](../catalog/career-work.md#面试与简历)和[校园与职场沟通](../collections/howto-series.md#学习与工作)。

## 家长与照护者

- 婴幼儿家长可查[亲子游戏](../catalog/family-relationships-care.md#亲子活动)的适用年龄。
- 老年人与照护者可查[养老服务入口](../catalog/family-relationships-care.md#养老服务)。

## 开发、研究与创作

- 会编程、刚学 Python 的开发者可查[开发与数据课程](../collections/handbooks-and-courses.md#开发与数据)。
- 做研究或写论文时，可查[文献工具与检索课程](../catalog/learning-research.md#查找和整理资料)。
- 刚开始制作图像、音频或手工时，可从[图像与音频](../catalog/creativity-hobbies.md#图像与音频)选小任务。
