# 发现实用资源

## 输入与目标

输入为用户问题、优先语言、适用地区和已知链接。先将宽泛主题缩成可完成的任务，查看现有主题页，记录缺口。

## 流程与输出

1. 用具体任务词检索官方文档、主管部门、大学、专业机构和维护中的开源教程。
2. 打开原发布方页面。核对作者、读者、版本、适用地区、可进入的正文或目录，以及已有条目是否覆盖同一任务。
3. 按来源政策输出候选名称、原始 URL、范围、类型、语言、简短用途、核验位置和待查项。发现过程可保存在忽略的工作目录或 Actions artifact。

## 失败与安全

访问受限或证据不足时记录实际结果和 unknown。避免绕过登录或访问控制。涉及医疗、税务、法律、金融与安全的操作，记录中国大陆候选依据并送人工复核。发现结果留在候选阶段。

## 示例与验收

输入“Android 换机如何确认有哪些备份”。返回终端系统官方文档及明确的版本或地区边界，指出设备差异。合格候选能追溯到发布者与具体内容。
