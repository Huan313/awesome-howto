# 核验目录资源

## 输入与目标

输入为候选链接、用途、分类和相关的现有主题页。以目录 Markdown 为正式内容来源，核对新增条目是否有独立价值。

## 流程与输出

1. 验证原始发布者、正文或目录及读者能完成的任务。校对版本、前置条件、地区和许可；只保留原创短描述与链接。
2. 去除跟踪参数后核对重复。选一个最合适的主题页存主条目，其他场景交叉引用。集合放入对应集合页。
3. 给出 accept、needs-review 或 reject 及简短理由。用目录校验器核对改动。高风险条目须有中国大陆原始依据、人工复核日期与可查的审核记录。

## 失败与安全

403、429 或网络超时记录为待复核。许可未知时只保留链接。缺少中国大陆依据或人工复核的高风险操作内容留在候选，可另外核验明确的官方服务入口。

## 示例与验收

对“按个人症状选择用药”的候选输出 needs-review 并保留来源缺口。目录复核通过的条目应有清楚的类型、语言和必要地区信息。
