# Awesome Lists 与资源索引

从这些索引继续发现独立资源，并回到原发布方核验。

## 开发与学习

- [Awesome](https://github.com/sindresorhus/awesome) — 从技术、平台和其他主题定位维护中的资源清单。`Awesome List` · `英文`
- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books) — 按语言和资料格式查开放可读的编程书目与学习资源。`Awesome List` · `中英双语`
- [Project Based Learning](https://github.com/practical-tutorials/project-based-learning) — 按编程语言定位第三方项目教程，可先选想做出的成果。`Awesome List` · `英文`

## 软件与创作

- [Awesome Mac](https://github.com/jaywcjlove/awesome-mac) — 按编辑、效率等用途筛查 macOS 软件与项目入口。`Awesome List` · `中英双语`
- [Awesome Fonts](https://github.com/brabadu/awesome-fonts) — 查找字体、排版参考和设计工具，使用前按各项目核对许可。`Awesome List` · `英文`
