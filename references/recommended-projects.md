# 项目、手册与课程

## 系统学习

- [MDN 学习 Web 开发](https://developer.mozilla.org/zh-CN/docs/Learn_web_development) — 从环境准备进入 HTML、CSS 和 JavaScript 的分模块练习，部分内容为英文。`课程` · `中英双语`
- [Pro Git](https://git-scm.com/book/zh/v2) — 按入门、分支、远程协作和内部原理查阅 Git 实例。`手册` · `中文`
- [OSSU Computer Science](https://github.com/ossu/computer-science) — 按先修、核心课程与进阶方向安排自学计算机科学。`学习路径` · `英文`
- [华东理工大学 · 文献检索](https://mooc.s.ecust.edu.cn/course/441650000027825.html) — 按数据库、检索方法和文献利用章节组织课程。`课程` · `中文`

## AI 与工作流

- [微软 Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) — 按课次学习生成式 AI 应用，并通过代码练习检查理解。`课程` · `中英双语`
- [Datawhale Hello-Agents](https://github.com/datawhalechina/hello-agents) — 从智能体基本概念进入框架、记忆与工具调用等章节和实作。`课程` · `中文`
- [OpenAI Cookbook](https://github.com/openai/openai-cookbook) — 按主题查阅 OpenAI API 实作示例及可运行笔记本。`手册` · `英文`
- [Microsoft Learn · Microsoft 365 Copilot](https://learn.microsoft.com/zh-cn/training/modules/copilot-office-applications/) — 按 Office 应用查生成、整理和汇总任务的学习单元。`课程` · `中文`
